WAR — Browser card game

1. Extract the ZIP into a folder.
2. Keep index.html, style.css, and script.js together.
3. Open index.html in Chrome, Edge, Firefox, or Safari.
4. Click Start Game, then Flip Cards. During a tie, click Continue War.

No installation, internet, database, or server needed.
Restart Game shuffles and deals a new game. How to Play explains the rules.
The game intentionally has no turn limit: War can take many rounds.
